# MLOps-Lab1: Project Structure and Continuous Integration (CI)

This repository hosts the foundational code for **MLOps Lab 1**, which focuses on setting up a robust, production-ready structure for a machine learning project and implementing automated testing.

### 🎯 Objective
* Establish a standard MLOps project layout (`api`, `cli`, `logic`).
* Implement unit and integration **testing** (`tests/`).
* Configure a **Continuous Integration (CI)** pipeline using GitHub Actions to automatically lint, format, and test the code upon every commit.

### 🛠️ Key Components
* Python 3.11 (`.python-version`)
* Code quality checks (`Makefile` targets for `lint`, `format`)
* GitHub Actions (`.github/workflows/CI.yml`)
